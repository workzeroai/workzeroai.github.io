Jev로 클로드를 10배 쓰는 법

출처 · Ben AI이 글은 아래 영상 내용을 한국어로 요약·정리한 것입니다. 원문의 주장과 수치는 영상 제작자의 것입니다.원제 · Jev Will 10x Your Claude (Here's How)

핵심
  • 분류와 라우팅은 텍스트 생성이 아니에요
  • 저렴함이 새로운 활용 사례를 만듭니다
  • Jev 단독이 아니라 Claude와 묶어야 진짜 힘이 나옵니다

한 줄 요약

ChatGPT 공동 창업자 중 한 명이 내놓은 새 AI 모델 'Jev'는 텍스트를 쓰는 대신 '결정'만 출력합니다. 그래서 일반 LLM보다 최대 200배 빠르고 400배 저렴하게 대량 분류·라우팅을 처리해요. Claude와 묶어 쓰면 리드 스코어링부터 이탈 예측, 브라우저 자동화까지 예전엔 비용 때문에 포기했던 자동화가 가능해집니다.

전체 내용 정리

Jev는 글을 쓰지 않고 결정만 내려요

Jev는 ChatGPT 공동 발명가 중 한 명이 출시한 새로운 유형의 AI 모델입니다. 속도는 일반 LLM보다 20~200배 빠르고 비용은 40~400배 저렴하며 출력 토큰은 무료예요.

입력값은 일반 거대 언어 모델과 같습니다. 근본적으로 다른 건 출력이에요. 인간과의 대화에 최적화된 텍스트 대신 오직 '결정'만 내놓습니다. 인간 피드백(RLHF)이 아니라 정교한 의사 결정을 위한 강화 학습으로 훈련됐기 때문에 이런 격차가 나요.

출력 가능한 값은 둘 중 하나입니다. 예/아니오/null, 또는 미리 정의해 둔 선택지 중 하나를 고르는 다지선다형 분류요. 텍스트 작성, 수학, 이미지 출력, 복잡한 추론은 할 수 없습니다.

그래서 대규모 데이터셋에서 분류나 라우팅 작업을 할 때 특히 유용하고, 글쓰기나 계산처럼 추론이 필요한 작업에는 쓸 수 없어요.

Claude에 붙이는 건 API 키 하나면 끝나요

사용법은 간단합니다.

typeset.ai 웹사이트에 무료로 가입해 로그인한 뒤 API 키를 생성하면 5달러가 무료로 제공되는데, 테스트해 보기엔 충분한 금액이에요.

Claude에서 쓰고 싶다면 이 API 키와 Jev의 문서 페이지 링크를 함께 넣어 주기만 하면 됩니다. 그러면 Claude가 Jev 사용법을 알아서 파악해요. 그다음엔 원하는 작업을 설명하기만 하면 되고, 어떤 방식(예/아니오형인지 다지선다형인지)을 쓸지는 Claude가 알아서 최적으로 설정해 줍니다.

댓글 1,400개 분류, Opus 5와 비교하면 격차가 확연해요

첫 번째 활용 사례는 지난 1년간 자신의 유튜브 채널에 달린 모든 댓글을 분석하는 거였습니다. 긍정, 부정, 건설적인 피드백, 답변되지 않은 질문, 답변된 질문 다섯 가지로 분류하고 CSV 파일과 대시보드로 출력하게 했어요. 이때 "분류할 때 일반 LLM을 쓰지 말고 Jev만 쓰라"고 지시했고요.

비교군이 인상적입니다. 같은 프롬프트와 워크플로를 Claude Opus 5로 실행했을 때는 일부 댓글을 건너뛰면서도 총 1,400개 댓글을 분석하는 데 34분이 걸리고 23달러가 들었어요.

신뢰성 면에서는 Jev가 Opus와 비슷한 수준이고 Sonnet보다는 낫다고 설명합니다. 즉 대량 분류 작업에서는 속도와 비용 차이가 압도적이라는 거예요.

리드 250명 스코어링은 4초, 1센트면 끝나요

또 다른 명확한 활용 사례는 잠재 고객 자격 요건 확인과 점수 매기기입니다.

250명의 잠재 고객 리스트를 "의사 결정권자인가", "미국에 거주하는가" 같은 자격 기준과 점수 체계에 따라 채점해 달라고 요청했어요. Jev API 키와 문서 페이지만 제공했는데도 4초 만에 250명 전체를 채점하고 1센트의 비용으로 점수가 포함된 엑셀 시트를 받았습니다.

여기서 한 걸음 더 나갈 수 있어요. 대규모 리드 리스트를 Jev로 빠르고 저렴하게 점수를 매긴 다음, Jev가 자격이 있다고 판단한 리드에 대해서만 Claude로 추가 조사나 아웃리치 메시지 작성을 맡기는 겁니다. 두 모델을 같은 워크플로에 통합하는 거죠.

이렇게 반복되는 작업은 Claude에게 "이 프로세스를 기술(skill)로 만들어 달라"고 요청하면 '제프로 리드 점수 매기기' 같은 재사용 가능한 기술로 패키징되고, 이후엔 이 기술을 실행할 때마다 자동으로 리드 점수를 매기게 됩니다.

저렴해서 새로 가능해진 일들

Jev는 분류 작업 자체가 워낙 저렴해서 예전엔 비용 때문에 시도하지 않았을 일들도 가능하게 만듭니다.

이탈 위험 예측 — 가입 후 경과일, 게시글 수, 마지막 로그인, 댓글 수, 참여한 미팅 횟수 같은 활동 데이터를 기반으로 지난달 신규 회원 203명의 이탈 위험도를 1~10점으로 채점하는 작업은 25초, 1센트에 끝났어요. 결과는 점수별로 색상까지 표시된 구글 시트로 받았고, 2주마다 자동으로 실행되는 기술과 예약 작업으로 만들어 뒀습니다.

고객지원 라우팅 — 지난 1년간의 커뮤니티 게시물 1,300여 개를 여섯 가지로 분류해 담당자에게 연결하는 작업은 106초, 4센트에 끝났어요. 커뮤니티 피드백, 기술 질문, 영업 질문, 비즈니스 질문, 소개, 성과로 나누고 기술 질문은 CTO에게 보내는 식이죠.

통화 분류 — 227건의 고객 지원 통화 기록을 여섯 가지 범주로 분류하는 작업도 13초, 7센트로 끝났습니다. 두 경우 모두 Claude가 분류 결과를 바탕으로 대시보드까지 만들어 줬어요.

브라우저 자동화에서도 속도를 뒤집어요

느리기로 유명한 브라우저 사용 자동화 영역에서도 Jev를 활용한 초고속 버전인 'Jev ultra fast'가 무료 GitHub 저장소로 공개돼 있습니다. 이걸로 취리히에서 런던으로 가는 항공편을 7초 만에 예약하는 시연을 보여 줘요.

이 저장소를 쓰려면 Claude Code가 필요한데, 이를 이용해 자신의 유튜브 피드를 스캔하는 브라우저 에이전트를 만들었습니다.

지시는 이랬어요. youtube.com을 열고 자기 계정의 AI 탭을 클릭한 뒤 5분간 피드를 스크롤하면서 화면마다 Jev로 "이 영상이 Claude 관련 영상인지"를 판단하게 하고, 맞으면 제목과 링크를 구글 시트에 추가하라.

그 결과 5분 동안 443개 영상을 확인해 그중 Claude 관련 영상 99개를 저장했고 비용은 1센트였습니다. 결과 시트에는 제목·채널·링크와 함께 실제로 Claude 영상일 확률 점수까지 담겨 있었어요(확률 55%로 표시된 한 건은 실제로는 Claude와 무관한 영상이었습니다).

이 외에도 방문자 유형에 따라 실시간으로 웹사이트 H1 태그나 문구를 바꾸거나, 작업을 적절한 언어 모델로 즉시 라우팅하는 등 다른 사람들의 활용 사례도 소개돼요.

핵심 인사이트

  • 분류와 라우팅은 텍스트 생성이 아니에요: 대량의 예/아니오, 다지선다형 판단에 범용 LLM을 쓰면 속도와 비용 모두 손해입니다. Opus 5와의 34분·23달러 대 초저비용 비교가 이를 명확히 보여 줘요.
  • 저렴함이 새로운 활용 사례를 만듭니다: 이탈 위험 예측이나 5분짜리 유튜브 피드 실시간 스캔처럼, 예전엔 비용 때문에 시도조차 안 했을 작업이 1센트대 비용 덕분에 실행 가능해져요.
  • Jev 단독이 아니라 Claude와 묶어야 진짜 힘이 나옵니다: Jev로 대량 데이터를 걸러 내고 Claude로 걸러진 대상만 심층 처리하는 조합, 그리고 이 워크플로 자체를 재사용 가능한 스킬과 예약 작업으로 만드는 게 핵심 패턴이에요.

오늘 당장 해볼 것

  1. typeset.ai에 무료로 가입해 API 키를 발급받아 보세요(5달러 무료 크레딧이 있습니다). Claude에 이 키와 Jev 문서 페이지 링크를 함께 넣고 테스트 요청을 해보면 됩니다.
  2. 반복적으로 발생하는 분류형 업무를 하나 골라 Jev로 먼저 돌려 보세요. 문의 분류, 리뷰·댓글 감정 분류, 리드 자격 확인 중 하나면 좋습니다. 속도·비용·정확도를 직접 확인해 보시고요.
  3. 결과가 만족스러우면 Claude에게 "이 분류 워크플로를 스킬로 만들고 주기적으로 자동 실행되도록 예약해 달라"고 요청하세요. 거기서부터 진짜 자동화가 시작됩니다.
