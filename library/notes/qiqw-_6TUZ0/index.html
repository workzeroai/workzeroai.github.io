마케터라면 알아 둘 Claude Cowork 활용법 8가지

출처 · Grace Leung이 글은 아래 영상 내용을 한국어로 요약·정리한 것입니다. 원문의 주장과 수치는 영상 제작자의 것입니다.원제 · Claude Cowork: 8 Use Cases Every Marketer Should Know (Full Tutorial)

핵심
  • 맥락 파일이 모든 결과물의 품질을 정해요
  • 한 번 세팅하는 구조가 핵심이에요
  • 커넥터가 Cowork를 파일 도구에서 마케팅 데이터 도구로 바꿔요

한 줄 요약

Grace Leung이 Claude Cowork로 마케팅 일을 하는 8가지 방법을 순서대로 보여 줘요. 폴더·맥락 파일 세팅, 전략 덱, Projects, 커넥터(Apify·Gamma), Live Artifacts, Skills와 플러그인, 브라우저 사용, 예약 작업까지 한 번 만들어 두면 계속 쓰는 구조를 짜는 영상입니다.

전체 내용 정리

Cowork는 Chat이 아니에요, 폴더와 맥락 파일을 깔고 그 위에서 전략 덱을 만들어요 (활용법 1·2)

Grace는 Claude Cowork를 설치하고도 Claude Chat처럼만 쓰는 사람이 많다고 봐요. Chat은 생각을 정리하거나 아이디어를 내거나 파일을 만들 때 좋은데, 모든 일이 클라우드에서 벌어져서 결과물을 복사하고 내려받아 다른 곳에 저장하는 일이 남거든요. Cowork는 로컬 데스크톱 에이전트(내 컴퓨터의 폴더와 파일 시스템에서 직접 일하는 AI)라서 파일을 읽고 외부 도구에 연결하고 완성된 결과물을 폴더 안에 바로 넣어 줘요.

Grace는 코딩 없이 일하고 싶은 비개발자라면 마케팅 업무의 80%는 Cowork가 맞는 자리라고 말해요.

활용법 1은 마케팅 워크스페이스를 세팅하는 거예요. Grace가 보여 준 순서는 이렇습니다.

  1. 컴퓨터에 폴더를 만들어요. 예시 브랜드는 Pet Pure이고 marketing 폴더 안에 context(브랜드 지식을 담는 곳), template(재사용할 마케팅 템플릿), project(마케팅 결과물) 폴더를 둬요. 더 필요하면 나중에 추가하면 된다고 해요.
  2. Claude Desktop에서 Settings, Cowork, Global Instructions로 들어가요. 모든 Cowork 세션에 적용되는 규칙을 적는 곳인데, Grace는 너무 자세히 쓰면 오히려 발목을 잡으니 한두 줄이면 충분하다고 해요. 예를 들면 작업을 시작하기 전에 항상 context 폴더부터 훑으라는 정도입니다.
  3. 브랜드 맥락 파일은 직접 쓰지 말고 Claude에게 질문을 시켜요. marketing 폴더를 불러오면(처음이면 접근 권한을 묻습니다) brand context, brand voice, ideal customer profile 세 파일을 만들어 달라고 하고 Ask User Question tool로 질문하게 한 다음 context 폴더에 저장하라고 해요.

그러면 Claude가 브랜드, 포지셔닝, 타깃 고객, 말투를 하나씩 물어보고 Grace는 답하거나 빠진 내용을 보태요. 몇 분이면 세 파일이 폴더에 저장돼요. 이후로는 이 폴더에서 새 작업을 시작할 때마다 Pet Pure가 누구이고 누구에게 말하고 어떤 톤인지 Claude가 이미 알고 있어서 같은 설명을 되풀이할 일이 없어요.

활용법 2는 그 맥락 파일로 전략 덱을 만드는 거예요. 마케터라면 전략 덱을 처음부터 만드느라 시간을 많이 쓰잖아요. Grace는 template 폴더에 브랜드 덱 템플릿을 넣고 따로 마케팅 이미지 폴더도 준비했어요. Cowork는 폴더를 한 번에 여러 개 불러올 수 있어서 marketing 폴더와 brand photos 폴더를 같이 로드했습니다.

프롬프트는 최신 마케팅 트렌드를 조사하고 성장 우선순위에 맞춰 브랜드 사진을 쓴 12슬라이드 전략 덱을 만들라는 내용이었어요. Claude는 맥락 파일과 글로벌 지침을 먼저 읽고 사진을 불러온 뒤 아웃라인을 짜고 전체 덱을 만들었어요. 결과물은 템플릿을 따르고 자리 표시 이미지를 실제 사진으로 바꿨고 전략도 일반론이 아니라 이 브랜드에 맞춰져 있었다고 Grace는 평가해요.

다만 일부 사진은 위치를 다시 잡아야 해서 완벽하진 않아요. 그래도 첫 초안은 내 로컬 폴더에 저장되죠.

Grace의 결론은 맥락이 좋을수록 결과가 좋다는 거예요(better context in, better quality out).

반복하는 일은 Projects에 담아요, 매주 만드는 캐러셀이 예시입니다 (활용법 3)

콘텐츠 제작처럼 매주 주제는 바뀌어도 모양은 일관돼야 하는 일이 있죠. Grace는 이런 워크플로를 위해 Cowork의 Projects를 써요. 대화와 작업이 정리되고 한 번 시스템을 세팅해 두면 다시 올 때마다 Claude가 할 일을 이미 알고 있어요.

Grace가 보여 준 세팅 순서입니다.

  1. Carousel Design System 폴더를 만들어요. 안에는 앞에서 쓴 브랜드 맥락 파일을 넣은 context 폴더, 마음에 드는 캐러셀 레이아웃 예시를 모은 reference 폴더, 완성 디자인을 저장할 output 폴더를 둬요.
  2. Cowork에서 Projects로 가서 Create a New Project를 눌러요. 선택지는 처음부터 시작, Claude 채팅에서 가져오기, 기존 폴더 사용 세 가지인데 폴더를 이미 만들었으니 마지막을 골라요.
  3. 프로젝트에는 자체 project instructions, 폴더의 context 파일, 자체 memory가 붙어요. Claude Cowork 안의 작업 공간 같은 거라고 Grace는 설명해요.
  4. Claude에게 reference 예시와 브랜드 맥락을 분석한 뒤 brand style guide와 carousel design system 파일을 만들라고 해요. 몇 번 주고받으면 두 문서가 프로젝트 폴더에 저장되고 앞으로 이 프로젝트에서 캐러셀을 만들 때마다 Claude가 따를 규칙이 됩니다.
  5. 마지막으로 project instructions를 써요. 이 프로젝트 전용 시스템 프롬프트로, Claude가 폴더를 어떻게 훑고 어떤 규칙을 따를지 적는 곳이에요. Grace는 프로젝트를 만들 때마다 이 단계를 하라고 강하게 권해요.

테스트는 반려동물 그루밍 모범 사례 글을 첨부하고 7슬라이드 캐러셀을 만들어 달라고 하는 거였어요. Claude는 context 파일과 디자인 시스템 파일을 불러와 규칙을 읽었고 브랜드 컬러와 깔끔한 레이아웃, 슬라이드마다 분명한 불릿을 갖춘 결과물을 output 폴더에 저장했어요.

이 방식은 캐러셀뿐 아니라 다른 마케팅 워크플로에도 그대로 써요. 기존 Claude Chat 프로젝트의 워크플로를 Cowork로 가져올 수도 있습니다.

커넥터로 외부 데이터를 끌어와요, 경쟁사 분석과 Gamma 슬라이드 (활용법 4·5)

Grace는 지금까지 한 일이 전부 컴퓨터 안의 파일 이야기였고 Cowork가 마케팅에서 진짜 강해지는 지점은 커넥터라고 말해요. 커넥터는 외부 도구에 Claude를 연결해 실시간 데이터를 가져오고 로컬 파일처럼 다루게 해 줘요.

활용법 4는 Apify로 경쟁사 소셜 포스트를 분석하는 거예요. 설정은 Customize, Connectors로 들어가는 것부터 시작해요. Google Drive와 Gmail 같은 기본 목록이 보이는데, Grace는 웹 스크래핑 도구인 Apify를 골라 Install을 누르고 API token으로 설정했어요.

그다음 Pet Pure 프로젝트에서 경쟁사별 최근 소셜 포스트 25개를 스크래핑하고 분석 결과를 스프레드시트로 정리하고 콘텐츠 전략에 쓸 인터랙티브 대시보드까지 만들라고 요청했어요. Claude는 브랜드 맥락을 읽은 뒤 Apify 커넥터로 경쟁사 계정을 하나씩 긁어 왔습니다.

  • 스프레드시트: 요약 탭에 경쟁사별 현황, 게시 빈도, 핵심 시사점이 있어요. 전체 포스트 상세에는 캡션과 참여율이 들어 있고 성과를 색으로 구분해 준 점을 Grace가 좋아했어요.
  • 대시보드: 상단 핵심 지표, 콘텐츠 유형별 참여율, 성과가 좋은 주제가 나오고 브랜드별로 필터를 걸 수 있어요. 실제 Instagram 포스트로 넘어가 확인할 수 있고 적용할 핵심 액션도 함께 보여 줘요.

전부 프로젝트 폴더에 저장돼요. Grace는 이게 커넥터 활용의 한 예일 뿐이고 내부와 외부의 여러 데이터 소스를 끌어올 수 있어서 로컬 파일만 쓸 때보다 훨씬 쓸모가 커진다고 해요.

활용법 5는 Gamma로 다듬어진 프레젠테이션을 만드는 거예요. 이 부분은 영상의 협찬 구간이기도 한데, 방법 자체는 따라 할 만해요. Claude도 프레젠테이션을 만들 수 있지만 더 세련되고 수정하기 쉬운 결과가 필요하면 Gamma를 쓰라는 게 Grace의 설명이에요. 지금은 Claude 안에서 Gamma가 기본 기능처럼 돌아가고 다른 커넥터와 함께 쓸 수도 있어요.

연결 순서는 이렇습니다. Customize의 Connectors 패널에서 Gamma를 검색해 Connect를 누르고 로그인하거나 가입한 뒤 워크스페이스를 고르고 Allow로 승인해요. Grace는 Gmail도 이미 연결해 둔 상태였어요.

그러고 한 프롬프트에 모두 담았어요. Gmail에서 팀이 보낸 Adobe AI traffic trends report를 찾고 핵심 인사이트를 뽑아서 Gamma에서 전문적인 테마의 10슬라이드 프레젠테이션으로 만들라는 요청이에요. Claude가 Gmail을 읽고 리포트를 처리한 뒤 Gamma를 호출했고 몇 분 만에 이미지, 차트, 콜아웃 박스가 들어간 덱이 Gamma에 나왔어요. 레이아웃은 한 번 클릭으로 바꾸고 색 구성도 쉽게 조정할 수 있어요.

Live Artifacts로 계속 갱신되는 마케팅 화면을 만들어요 (활용법 6)

Grace가 가장 기대하는 기능이 Live Artifacts예요. 한 번 출력하고 끝나는 정적인 결과물이 아니라, 실시간 데이터가 연결된 인터랙티브 페이지가 계속 남아 있는 거죠. 한 번 만들어 두면 열 때마다 그 자리에 있어요(Build it once, and it's just there).

먼저 기능을 켜야 해요. Settings의 Capabilities에서 Artifacts, AI-powered artifacts, Code Execution을 모두 켭니다.

만드는 방법은 두 가지예요. 하나는 Live Artifacts 메뉴에서 New Artifacts를 누르는 건데, 이러면 커넥터를 불러와 인터뷰하듯 만드는 과정을 안내해 줘요. Grace가 시연에서 쓴 건 두 번째로, 프로젝트 폴더에서 바로 만드는 방법이에요.

시연 주제는 자기 브랜드의 AI search visibility radar였어요. Ahrefs와 Google Search Console 커넥터를 미리 연결해 뒀고 커넥터가 있어야 라이브 아티팩트가 쓸모 있다고 Grace는 강조해요. 프로젝트 폴더를 불러온 뒤 두 데이터 소스를 쓰는 live artifact를 만들되, 주간 우선순위 브리프(weekly priority brief), 키워드 기회(keyword opportunities), 내 분야의 새 검색어(new queries) 섹션을 넣으라고 요청했어요. Grace의 팁은 프롬프트에 live artifacts라는 단어를 꼭 넣는 거예요. 안 그러면 Claude가 의도를 못 알아챌 수 있거든요.

Claude는 두 커넥터를 호출해 데이터를 가져온 다음 생성해도 되는지 확인을 구해요. 첫 버전에 빠진 데이터가 있으면 마음에 들 때까지 계속 수정을 요청하면 되고 그게 정상이라고 Grace는 말해요.

결과물은 이래요.

  • 브랜드 컬러로 나오고 맨 위에 이번 주 우선순위가 요약돼요. 사이트가 클릭을 잃는 곳과 집중할 곳이 보여요.
  • 그 아래에 정렬이 되는 롱테일 키워드 기회와 내 분야에 맞는 새 검색어가 나와요.
  • 전체 목록을 CSV로 한 번에 내보내서 팀이나 고객과 공유할 수 있고 화면 전체를 PDF 리포트로 내려받을 수도 있어요.

핀 아이콘으로 고정하면 사이드바에 남아요. 라이브라서 새로고침만 누르면 최신 데이터를 가져오고 대화를 처음부터 다시 돌릴 필요가 없어요. Grace는 내가 가까이서 지켜보고 싶은 마케팅 지표가 무엇인지 떠올려 보고 같은 방식으로 추적 화면을 만들어 보라고 해요.

같은 일을 반복한다면 Skills와 플러그인으로 묶어요 (활용법 7)

워크플로를 몇 개 만들다 보면 캠페인마다 리드 마그넷(잠재 고객 연락처를 받으려고 내놓는 자료)을 만들거나 고객마다 리포트를 만드는 식으로 같은 설명을 되풀이하게 돼요. Grace는 이럴 때 Claude Skills(작업 방법을 적어 둔 재사용 지시서)를 쓰라고 해요. 워크플로를 한 번 해 보고 패키지로 묶어 두면 Claude가 같은 품질로 필요할 때마다 반복해요.

Customize에서 Skills 라이브러리로 들어가요. 설치한 스킬이 없다면 공식 스킬을 둘러보고 마음에 드는 걸 추가하면 되고 내 스킬을 만들 때 필요하니 skill-creator 스킬은 꼭 설치하라고 Grace는 권해요.

시연은 이런 흐름이었어요.

  1. research 폴더에 경쟁사 비교, 고객 FAQ, 설문 데이터, 모범 사례, 문서 같은 자료를 모아 둬요. 채팅에 일일이 첨부할 필요 없이 폴더를 가리키고 훑게 하는 것도 Cowork의 장점이에요.
  2. 마케팅용 Cowork 프로젝트에 project instructions를 써서 큰 맥락과 프로젝트 구조를 알려 줘요.
  3. 이 자료로 8페이지 PDF 리드 마그넷을 만들되, 먼저 아웃라인을 제안하고 승인을 받고 모든 걸 브랜드에 맞추라고 요청해요.
  4. Claude가 8페이지 구성안을 내놓고 Grace가 확인하면 전체 가이드를 제작해요.

결과물의 레이아웃, 디자인, 타이포그래피 위계는 탄탄했어요. 아쉬운 건 브랜드 오렌지를 너무 많이 쓰지 않았으면 했다는 점이고 마음에 든 건 스코어카드와 자가 진단 섹션, 잠재 고객이 실제로 해 볼 수 있는 마지막 액션 플랜이었어요. Show in the folder를 누르면 파일이 lead magnet 폴더에 저장돼 있어요.

여기서부터가 핵심이에요. 만족스러우면 Claude에게 이 워크플로를 뽑아내서 Lead Magnet PDF Builder라는 재사용 스킬로 패키징하라고 해요. 자료가 무엇이든 리드 마그넷으로 만드는 스킬이고 Grace는 Pet Pure 전용이 아니라 어떤 브랜드에서도 돌아가도록 brand agnostic하게 만들라고 지시해요. Claude가 skill-creator로 만들어 주면 Save Skill을 한 번 눌러 내 계정에 설치해요. 다음에는 어떤 브랜드든 자료만 넣고 스킬을 실행하면 같은 품질과 구조가 나옵니다.

직접 만들기 싫다면 Anthropic의 공식 Marketing 플러그인(스킬, 명령어, 에이전트 같은 도구를 묶은 번들)을 설치하는 길도 있어요. 설치 순서는 이렇습니다.

  1. Connectors 패널의 personal plugin에서 Browse Plugin을 눌러요. 공식 플러그인을 둘러보는 것 외에 직접 올리거나 서드파티 플러그인을 가져올 수도 있어요.
  2. marketing을 검색해서 공식 마케팅 플러그인을 Install해요. 여기에는 brand review, campaign plan, competitive brief 등 미리 만든 마케팅 스킬 8개가 들어 있어요.
  3. 마케팅 프로젝트에서 슬래시 명령을 열고 competitive brief를 검색한 뒤, 우리 브랜드를 경쟁사와 비교해 보기 좋게 포맷한 문서 리포트를 만들라고 프롬프트를 적어요.

Claude가 입력을 받는 인터랙티브 인터뷰 패널을 띄우고 이어서 리서치를 거쳐 웹 출처 링크가 붙은 최종 문서를 내놓아요. Grace는 Claude가 만드는 분석 리포트가 늘 구조가 좋고 브랜딩을 따르고 차트와 표 같은 시각 자료가 풍부해서 인상적이라고 해요. 한 번에 완벽한 결과가 나오는 일은 드문 만큼 이어서 수정하라는 말도 덧붙여요.

브라우저 사용과 예약 작업으로 AI 검색 노출을 매주 자동 추적해요 (활용법 8)

Grace는 브라우저 사용이 좀 놀라운 기능이라고 해요. Cowork가 웹을 직접 돌아다니며 클릭하고 스크롤하고 실제 사이트를 탐색하거든요. 파일이나 API만으로는 안 되는 마케팅 작업이 있잖아요. 누군가 사이트에 가서 검색하고 나오는 걸 봐야 하는 일이요. 번거로운 수작업이었는데 이제 Cowork가 대신해 줘요.

켜는 방법은 두 단계예요. Customize의 Connectors에서 Claude in Chrome 확장 프로그램이 활성화됐는지 확인하고 Chrome 웹 스토어에서 Claude를 검색해 설치해요. Anthropic이 낸 공식 확장인지 꼭 확인하라고 Grace는 당부해요.

시연 과제는 AI 검색 가시성 추적이었어요. 브랜드가 AI 검색에서 노출되길 원하는 타깃 프롬프트 목록(AI search prompt list)을 준비해 두고 Pet Pure Marketing 프로젝트에서 이 목록을 읽어 Google AI mode, ChatGPT, Perplexity에서 검색하라고 해요. 캡처할 항목을 지정하고 결과를 주간으로 비교할 수 있는 Excel 트래커로 정리하라는 요청까지 한 프롬프트에 담았어요.

Claude는 Claude in Chrome 도구를 호출해 브라우저 사용 권한을 묻고 새 Chrome 세션을 열어 Perplexity, ChatGPT, Google AI mode 순서로 AI 검색 결과를 하나씩 캡처해요. 전체 과정이 백그라운드에서 돌아서 지켜볼 필요가 없고 15~20분 뒤에 Excel 트래커가 나와요.

  • 원본 데이터 탭: 캡처한 raw data가 들어 있고 브랜드가 순위에 오르지 못한 프롬프트를 강조해 줘요. 가장 많이 인용된 브랜드 URL 같은 열도 있어요.
  • 인사이트 탭: 플랫폼별 가시성, 상위 경쟁 브랜드, 색으로 구분한 기회 격차를 요약하고 차트도 넣어 줘요.

첫 주라서 주간 추세 칸은 비어 있어요. 다시 실행하면 새 탭에 데이터가 쌓이고 Claude가 인사이트 탭을 갱신하니 추세를 볼 수 있고 raw 스프레드시트를 따로 받아 맞춤 대시보드를 만드는 방법도 있어요.

여기서 한 걸음 더 가면 예약 작업이에요. 이 Cowork 프로젝트의 Schedule 섹션에서 Add를 눌러 새 예약 작업(scheduled task)을 만들고 이름, 설명, 세부 내용을 적어요. 세부 내용에는 방금 쓴 프롬프트를 그대로 붙여 넣고 실행하라고만 하면 돼요. 그다음 폴더와 주기를 고르는데, Grace는 매주 일요일 오전 9시로 정했어요. 만들어 둔 작업은 클릭하면 세부 내용을 다시 보거나 고칠 수 있어요.

Grace가 제안한 자동화 아이디어는 다섯 가지예요: 주간 콘텐츠 브리프, 주간 리드 생성 리포트, 월간 캠페인 성과 리포트, 월간 뉴스레터 초안, 주간 경쟁사 다이제스트. 예약 작업을 앞에서 만든 Live Artifacts와 합치면 스스로 갱신되는 마케팅 컨트롤 센터를 Cowork 안에서 돌리는 셈이라고 Grace는 말합니다.

핵심 인사이트

  • 맥락 파일이 모든 결과물의 품질을 정해요: Grace는 브랜드 context, brand voice, ideal customer profile 세 파일을 한 번 만들어 두면 덱, 캐러셀, 리포트가 일반론이 아니라 이 브랜드에 맞게 나온다고 봐요. 설명을 되풀이하는 시간이 사라지는 게 가장 큰 이득이에요.
  • 한 번 세팅하는 구조가 핵심이에요: Projects는 규칙을, Skills는 작업 방식을, Live Artifacts는 화면을, 예약 작업은 실행 시점을 한 번만 만들어 두게 해 줘요. Grace가 보여 준 8가지는 모두 다시 설명하지 않아도 되게 만든다는 같은 원리 위에 있어요.
  • 커넥터가 Cowork를 파일 도구에서 마케팅 데이터 도구로 바꿔요: Apify, Gmail, Gamma, Ahrefs, Google Search Console처럼 실제 데이터가 흐르는 도구를 연결해야 경쟁사 분석과 키워드 화면이 쓸모가 생겨요.
  • 한 번에 완벽한 결과는 드물어요: 사진 위치가 어긋난 덱, 오렌지를 많이 쓴 PDF, 첫 버전에 비어 있던 데이터처럼 Grace는 반복해서 수정을 거치는 걸 정상으로 봐요.

오늘 당장 해볼 것

  1. 컴퓨터에 marketing 폴더를 만들고 안에 context, template, project 폴더를 나눠 보세요. Claude Desktop의 Settings, Cowork, Global Instructions에 "작업 전에 context 폴더부터 확인해" 같은 한두 줄만 적어 두면 이후 모든 세션에서 맥락을 먼저 읽어요.
  2. Cowork에서 marketing 폴더를 불러오고 "brand context, brand voice, ideal customer profile 세 파일을 만들어 줘. Ask User Question tool로 나에게 질문하고 다 끝나면 context 폴더에 저장해"라고 요청해 보세요. 질문에 답하는 몇 분이면 이후 작업의 바탕이 생겨요.
  3. 매주 반복하는 콘텐츠 작업이 있다면 Projects에서 Create a New Project, 기존 폴더 사용으로 시작해 보세요. reference 폴더에 좋아하는 예시를 넣고 style guide와 design system 파일을 만들게 한 뒤, project instructions까지 적으면 다음 주부터는 새 주제만 넣으면 돼요.
  4. Customize의 Skills에서 skill-creator를 설치하고 이미 만들어 본 결과물 하나를 "브랜드에 상관없이 쓸 수 있는 스킬로 패키징해 줘"라고 요청해 보세요. 마음에 들면 Save Skill로 저장해요.
  5. Settings의 Capabilities에서 Artifacts, AI-powered artifacts, Code Execution을 켜고 Ahrefs나 Google Search Console 같은 커넥터를 연결한 뒤, "live artifact로 주간 우선순위 브리프와 키워드 기회 화면을 만들어 줘"라고 해 보세요. 프롬프트에 live artifact라는 단어를 넣는 게 요령이에요.
