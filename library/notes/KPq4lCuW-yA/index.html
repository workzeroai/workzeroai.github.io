AI한테 "알아서 운영해" 했더니 라이브 중에 제 계정을 키우고 있었습니다

출처 · 윤자동이 글은 아래 영상 내용을 한국어로 요약·정리한 것입니다. 원문의 주장과 수치는 영상 제작자의 것입니다.
원본 영상 보기 →
핵심
  • 판단까지 위임하는 자동화예요
  • API가 없어도 브라우저로 우회 가능해요
  • 디테일 하나가 노출을 좌우해요

한 줄 요약

쓰레드 계정을 "네가 알아서 24시간 운영해봐"라는 한 마디로 AI에게 통째로 맡겼어요. 그런데 유튜브 라이브 방송 중에, AI가 실제로 글을 쓰고 댓글을 달고 팔로워를 늘리고 있는 걸 실시간으로 확인하게 된 영상입니다.

전체 내용 정리

쓰레드 24시간 자동 운영을 AI에게 통째로 위임했어요

윤자동은 AI에게 "쓰레드를 24시간 자동으로 운영하고 싶다"는 지시 하나만 내렸습니다.

내용은 이랬어요. API 호출 개수의 최대치와 계정이 정지당하지 않을 범위를 AI가 스스로 파악하고, 자동화 관련 콘텐츠와 일상 콘텐츠를 섞어서 글쓰기·댓글 달기·리포스트·인용·다른 글에 소통하기·내 글에 댓글 달리면 답글 달기까지 전부 알아서 하라고요.

API가 지원되지 않는 기능은 브라우저를 직접 열어서 처리하라고 덧붙였습니다. 그리고 "나는 더 이상 손대지 않을 거니까 10분마다 확인하든 1시간마다 확인하든 네가 알아서 판단해서 한 달 내내 계정을 잘 운영해봐"라는 말과 함께 실행을 시작시켰어요.

카카오톡 단체방 공지도 브라우저 자동화로 동시에 돌렸어요

그는 같은 방식을 카카오톡에도 적용해 보여줬습니다.

"윤자동과 함께하는 업무자동화" 단체방에 지금 유튜브 라이브를 시작했으니 다 들어오라는 공지를, 올 멘션과 링크까지 포함해서 올리라고 지시했어요. 이때 두 개의 에이전트가 동시에 돌아갔습니다. 하나는 카카오톡을 제어하고 다른 하나는 브라우저로 쓰레드를 제어하는 구조였죠.

처음에는 AI가 "올 멘션" 대신 "전체" 멘션으로 잘못 처리했어요. 그가 직접 "올 멘션을 왜 안 하냐"고 지적하며 다시 시키자 제대로 고쳐졌습니다.

그는 이런 자동화가 특히 유용한 업종을 짚었어요. 휴대폰 대리점처럼 매일 아침 여러 단체방에 정책 공지를 컨트롤 C·V로 반복해서 올려야 하는 곳이요.

이 과정에서 쓰레드 브라우저가 다른 계정으로 로그인돼 있는 걸 발견하고, 쓰레드를 제어하는 도구를 코덱스로 바꿔서 다시 시도하기도 했습니다.

쓰레드에 실시간으로 글을 쓰고, 링크 미리보기 이미지까지 직접 지웠어요

그가 설명하는 동안 브라우저를 제어하던 AI가 실제로 쓰레드에 글을 올렸습니다. "지금 유튜브 라이브 시작했습니다. 자동화 18년차가 알려준 바이브 자동화 꿀팁 실시간으로 이야기하고 있어요"라는 내용이었어요.

이후 프로필에 들어가 방금 올린 글을 스크롤로 찾아 댓글을 열고 링크를 남겼는데요. 쓰레드 특성상 링크를 남기면 OG 이미지(썸네일)가 자동으로 딸려 들어오잖아요. AI는 이 썸네일 옆의 X 버튼을 눌러 이미지를 직접 제거했습니다.

여기서 중요한 팁이 나와요. 그는 여러 번 테스트해본 결과 OG 이미지가 붙어 있으면 노출이 최소 30% 이상 줄어드는 걸 확인했다며, 링크를 남길 때는 반드시 미리보기 이미지를 제거하는 게 좋다고 강조했습니다.

방치해둔 사이 AI가 스스로 콘텐츠 엔진과 경험 데이터베이스를 만들고 버그까지 잡았어요

설명 도중 그는 앞서 걸어둔 "한 달 내내 알아서 운영해봐"라는 지시를 까맣게 잊고 있었다는 걸 떠올리고 프로필 활동을 확인했어요.

AI는 그 사이 스스로 계획을 세우고 실행하고 있었습니다.

원본 콘텐츠를 기록하고 쓰기 액션을 테스트하고, 키워드 서치 엔진을 짜서 콘텐츠 씨앗 73개를 생성했으며, "경험 은행"이라는 이름으로 경험 기반 콘텐츠 468건을 확보했다고 보고했어요.

다만 AI 스스로 품질 문제도 짚었습니다. AI가 그의 실제 경험을 자기 말투로 바꿔 쓰면서 화자가 뒤섞이는 문제가 있었고, 내부 운영 수치에도 이상이 있었다고요. 또 게시 확률이 특정 시간대에 항상 0으로 계산되는 시간 계산 버그도 스스로 발견해 기록해뒀습니다.

다른 사람들이 AI와 대화하는 동안 팔로워와 DM이 실제로 늘고 있었어요

활동 기록을 넘겨보니 15분 전에 달린 댓글이 있었습니다.

한 이용자가 "쓰레드 자동화를 해야겠네요"라고 남기자, AI는 "쓰레드 자동화는 저도 안 해봤습니다"라고 답글을 달아뒀어요. 정작 이 계정 자체가 자동화로 운영되고 있다는 점에서, 그는 이 답변을 보고 웃었습니다.

3분·5분·8분·9분 전에도 다른 이용자들의 댓글과 그에 대한 AI의 답글이 이어지고 있었고, 이 과정에서 팔로워가 늘어나고 있었어요. 라이브 방송을 진행하는 동안에도 실제로 DM이 들어와 그가 놀라는 모습도 나옵니다.

그는 방송을 마치면 AI를 끄고 그동안 무슨 일이 있었는지 자세히 확인해보겠다고 말하며 영상을 마무리했어요.

핵심 인사이트

  • 판단까지 위임하는 자동화예요: "네가 알아서 판단해"라는 한 문장으로 콘텐츠 기획·작성·발행·소통 전 과정을 AI에게 넘겼습니다. 반복 작업 대행을 넘어 운영 판단 자체를 위임할 수 있다는 걸, 실제 계정으로 보여준 사례죠.
  • API가 없어도 브라우저로 우회 가능해요: 쓰레드나 카카오톡처럼 공식 API가 제한적인 채널도 AI가 브라우저를 직접 조작해 처리했습니다. 자동화 가능 여부를 API 유무로만 판단할 필요가 없다는 걸 보여주죠.
  • 디테일 하나가 노출을 좌우해요: 링크를 남길 때 자동으로 붙는 미리보기 이미지를 지우느냐 마느냐로 노출이 30% 이상 갈렸습니다. 채널 알고리즘의 작은 습관 하나가 도달률에 직접 영향을 주는 거예요.

오늘 당장 해볼 것

  1. 매일 아침 여러 카카오톡 단체방에 같은 공지(정책 안내, 이벤트 안내 등)를 반복해서 올리고 있다면, 그 문구와 반복 패턴을 정리해서 자동화 업체에 "이 공지를 자동으로 올릴 수 있는지" 견적을 물어보세요.
  2. 쓰레드나 인스타그램에 외부 링크를 남길 때는 게시물 본문 대신 댓글에 링크를 걸고, 자동으로 붙는 미리보기 썸네일을 지운 채로 올려보세요. 이번 주 게시물부터 바로 적용해보시면 좋아요.
  3. 본인 SNS 계정에서 반복적으로 하는 작업(글쓰기, 댓글 응대, 리포스트)을 목록으로 적어보고, 그중 하나만 골라 자동화 업체에 위임 가능 여부를 문의해보세요.
