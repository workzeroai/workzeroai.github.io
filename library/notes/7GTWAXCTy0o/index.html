AI 자문단을 만들었어요 — 버핏·베조스가 내 사업을 토론한다면

출처 · Nate Herk | AI Automation이 글은 아래 영상 내용을 한국어로 요약·정리한 것입니다. 원문의 주장과 수치는 영상 제작자의 것입니다.원제 · I Built the Ultimate AI Board of Advisors
원본 영상 보기 →
핵심
  • 에이전트마다 '뇌' 폴더를 따로 채웠어요
  • 한 명에게 묻는 대신 여럿이 토론하고 투표해요
  • 토론 화면은 없어도 돌아가요

한 줄 요약

Nate는 베조스, 워런 버핏, 알렉스 호르모지 같은 사업가 7명을 Claude Code 서브에이전트로 만들어 자기 사업의 자문단으로 쓰고 있어요. 질문 하나를 던지면 이들이 서로 토론하고 투표한 뒤 결론을 PDF로 정리해 주는 구조인데, Nate는 이 스킬을 무료로 나눠 주겠다고 해요.

전체 내용 정리

유명 사업가 7명이 한 방에서 내 사업을 두고 싸워요

Nate는 영상 첫마디부터 베조스, 그레이엄, 호르모지, 게리 V(Gary Vee), 댄 마텔(Dan Martell), 위크맨, 워런 버핏이 자기 사업을 운영하고 있다고 말해요. 물론 진짜 사람들이 아니라 언제든 대화할 수 있는 Claude 에이전트로 만든 거예요. Nate는 이 공간을 '로스트 룸(Roast Room)'이라고 불러요.

쓰는 방법은 단순해요. 로스트 룸에 프롬프트를 하나 던지면 에이전트들이 서로 토론하고 논쟁해요. 화면에서는 호르모지가 베조스와 맞붙고, 게리 V가 워런 버핏과, 댄 마텔이 게리 V와 차례로 논쟁하는 모습이 보여요.

토론이 끝나면 각 선택지를 두고 실제로 투표를 해요. 그 결과로 PDF 파일이 하나 만들어지는데 여기엔 위원회의 결정, 평균 가중치 점수, 추천 사항, 핵심 포인트가 담겨요. 위원회가 최종 결론에 어떻게 도달했는지 그 과정까지 들어가고요.

에이전트마다 인물 자료를 담은 '뇌'가 따로 있어요

안을 열어 보면 구조가 보여요. .claude 폴더 안에 베조스, 버핏, 게리 V, 그레이엄, 호르모지, 마텔, 지노 위크맨(Gino Wickman) 에이전트가 하나씩 있어요. 로스트 룸을 실행하면 Claude Code가 이 7개 서브에이전트를 모두 불러와 각자의 지식을 활성화해요.

핵심은 'brains'라는 폴더예요. 인물마다 정보가 따로 정리돼 있거든요. 알렉스 호르모지라면 그의 책, 프레임워크, 입장, 원칙, 출처, 일화, 말투까지 들어 있어요.

Nate 설명으로는 수많은 공개 영상과 강연에서 130만 단어 이상의 데이터를 긁어 와 호르모지 서브에이전트의 '뇌'에 담았대요. 그러니까 화면에서 보이는 토론은 결국 이렇게 지식을 채운 서브에이전트들이 서로 대화하는 모습이에요.

화려한 화면은 없어도 돼요

Nate는 이런 시각적 인터페이스가 꼭 필요한 건 아니라고 말해요. 같은 세션을 Claude Code 안에서 그대로 돌리면 화면 연출 없이 결과물만 깔끔하게 나와요. 필요한 정보는 Claude Code 안에서 바로 확인할 수 있고요.

영상은 여기서 마무리돼요. Nate는 이 스킬을 무료로 체험해 보고 싶으면 댓글에 'roast room'이라고 남기라고 해요. 그러면 바로 보내 주겠다고요.

핵심 인사이트

  • 에이전트마다 '뇌' 폴더를 따로 채웠어요: Nate는 인물 이름만 붙인 게 아니라 책·프레임워크·원칙·말투를 정리한 자료를 인물마다 따로 넣어 뒀어요. 호르모지 서브에이전트의 '뇌'에는 공개 영상과 강연에서 모은 130만 단어 넘는 자료가 들어갔다고 해요.
  • 한 명에게 묻는 대신 여럿이 토론하고 투표해요: 로스트 룸에서는 에이전트끼리 서로 논쟁한 뒤 선택지마다 투표하고, 평균 가중치 점수와 추천 사항이 나와요. 위원회가 결론에 이른 과정까지 PDF에 남고요.
  • 토론 화면은 없어도 돌아가요: 화면에 보이는 토론은 Claude Code 서브에이전트들이 서로 대화하는 모습이에요. Nate는 시각적 인터페이스가 꼭 필요하진 않고, Claude Code 안에서 같은 세션을 돌려도 결과물을 바로 확인할 수 있다고 설명합니다.

오늘 당장 해볼 것

  1. 내 사업에 조언을 듣고 싶은 인물 2~3명을 골라 각자의 책 요약, 원칙, 자주 쓰는 말투를 문서 하나씩으로 정리해 보세요. Nate의 'brains' 폴더를 작게 따라 해 보는 첫걸음이에요.
  2. Claude Code에서 그 문서를 하나씩 참조하는 서브에이전트를 만들고, 지금 고민 중인 결정 하나를 던져 서로 반박하게 해 보세요. 한 명에게 묻는 것과 답이 어떻게 다른지 비교하면 감이 옵니다.
  3. 토론 뒤에는 선택지마다 점수를 매기고 근거를 한 장으로 정리해 달라고 요청해 보세요. 나중에 "왜 그렇게 결정했지?"를 되짚을 때 그대로 꺼내 볼 수 있어요.
