AI 직원이 카톡 답장한다고? 4천 명 오픈채팅방에서 실제로 쓰는 법 공개

출처 · 윤자동이 글은 아래 영상 내용을 한국어로 요약·정리한 것입니다. 원문의 주장과 수치는 영상 제작자의 것입니다.

핵심
  • 카톡봇은 읽기·생각하기·보내기 3단계로 나눠 보면 쉬워져요
  • 잘 만든 봇은 답하는 능력보다 입 다무는 판단이 핵심이에요
  • 정지 위험은 감수하고 시작해야 해요

한 줄 요약

4천 명 오픈채팅방을 운영하는 윤자동이 라이브에서 카카오톡 자동화의 원리와 방법 네 가지(메신저봇R·카카오 CLI·윈도우 PC 카톡·리눅스 서버+아이리스)를 비교하고, 24시간 답장하는 AI 직원 '클과장'의 실제 구조와 관리 화면까지 공개해요. 계정 정지 위험과 운영 규칙도 본인 경험을 바탕으로 짚어 줍니다.

전체 내용 정리

라이브 공지도, 강퇴도 AI가 카톡 화면을 직접 조작해요

라이브는 시연으로 시작해요. 윤자동이 Claude Code에 "단톡방에 라이브 시작했다고 링크와 함께 공지해 줘"라고 말하자, AI가 카톡 관련 메모리와 스킬 문서를 스스로 읽고 오늘 라이브 기록 폴더에서 공지 내용을 찾아요. 보내기 전에는 "최근 30분 동안 보낸 공지가 없으니 이 문구로 보낼게"라며 승인을 받고요. 전체 멘션을 추가로 요청하자, 예전에 성공했던 카톡 화면 조작 경로로 골뱅이를 치고 올 멘션을 건 뒤 직접 타이핑해서 전송까지 마쳐요.

전송 뒤에는 검증도 스스로 해요. 내 계정으로 올라갔는지, 전체 멘션이 걸렸는지, 링크 썸네일이 붙었는지 확인하고 그 결과를 프로젝트 기록 파일에 남기거든요. 윤자동은 모든 작업을 MD 파일로 기록하게 해 둔다고 해요. 사람이 하는 것보다 느릴 수는 있지만, 시켜 놓고 다른 일을 하면 끝나 있기 때문에 여러 일을 동시에 맡길 수 있다는 게 핵심이에요. 같은 방식으로 Threads에 라이브 공지를 올리는 것도 바로 보여 줘요.

오픈채팅방 인원 정리도 자동이에요. 매일 낮 12시에 '카카오 데일리 킥'이 실행돼 오래 말이 없던 기본 닉네임 참여자 10명을 내보내는데, 먼저 예고 공지를 올리고 닉네임을 검색한 뒤 캡처한 이미지로 진짜 기본 닉네임이 맞는지 AI가 한 번 더 확인해요. 실제 결과에 영향을 주지 않고 직전까지만 돌려 보는 테스트는 드라이런(dry run)이라고 부르고요. 다만 이날은 방송용으로 화면 해상도를 키워 둔 탓에 강퇴 단계가 제대로 작동하지 않았어요.

카톡 자동화가 절실한 곳은 따로 있어요

친구와 대화하는 용도라면 카톡 자동화가 꼭 필요하지는 않아요. 그런데 반복 업무가 카톡에서 쏟아지는 곳이 있다고 해요. 예로 든 휴대폰 판매점은 매일 바뀌는 판매 정책을 표 이미지로 만들어 아침마다 수십 개 카톡방에 일일이 보내고 있대요. 카톡으로 "이거 세 박스 보내 주세요" 같은 발주를 자연어로 받아 엑셀에 옮기고 다시 메일로 보내는 곳도 많고요.

윤자동이 클과장을 만든 이유도 비슷해요. 4천 명 방에서 같은 질문이 매일 반복되고, 같은 링크를 주며 같은 답을 하는 게 스트레스였대요. 카톡 AI 직원은 자주 묻는 질문에 정해 둔 자료로 답하고, 긴 대화를 요약하고, 유튜브 링크와 사진을 읽고, 정해진 시간에 알림을 보낼 수 있어요. 가게·1인 사업자라면 가격·위치·예약 문의에 답하고, 자체 재고 시스템과 연동해 재고 수량까지 안내하게 만들 수도 있다고 해요.

스팸 발송 용도로는 절대 쓰면 안 된다는 경고도 거듭 나와요. 전화번호 1만 개를 모아 홍보 메시지를 뿌리면 계정이 바로 정지된다는 거죠. 원래 사람이 하던 반복 업무를 대신 시켜 시간을 아끼는 용도로 써야 한다는 게 윤자동의 기준이에요.

카톡을 읽는 방법은 네 가지, 그중 하나는 절대 피해야 해요

카톡봇의 원리는 단순해요. 읽고, 생각하고, 보내는 3단계죠. 가운데 '생각' 단계에 AI가 꼭 필요한 건 아니라고 해요. 윤자동은 ChatGPT가 나오기 전부터 카톡봇을 만들어 왔는데, 그때는 기상청 사이트를 스크래핑해 날씨를 보내는 식이었거든요.

읽는 방법은 휴대폰 푸시 알림 읽기(안드로이드), 대화 기록 DB 직접 접근(맥·안드로이드, 아이폰은 안 됨), 화면 복사(주로 윈도우), 카카오 서버 직접 접속 이렇게 네 가지예요. 마지막 방식은 바로 계정이 정지될 수 있어서 찾아보지도 말라고 해요. 그렇다고 나머지 세 가지가 안전하다는 뜻도 아니에요. 카카오는 이런 사용을 약관 위반이나 부정 사용으로 볼 수 있고, 윤자동 본인도 일시 정지, 60일 정지, 이의 제기까지 거절당한 영구 정지를 모두 겪었다고 해요.

공식 기능으로는 카카오톡 채널 챗봇(사업자용, 안전하지만 1:1 문의 용도뿐), 오픈채팅 방장봇(AI가 아니라 키워드에 정해진 답만 반복)이 있어요. 이날 다룬 건 직접 만드는 봇이에요.

안드로이드는 메신저봇R, 맥은 카카오 CLI가 출발점이에요

메신저봇R은 플레이스토어에 있는 무료 안드로이드 앱이에요. 앱 안에서 "어떤 방에서 누가 어떤 메시지를 보내면 이렇게 답하라"는 스크립트를 짜는 방식인데, 예전엔 일일이 코딩해야 했지만 지금은 AI가 많이 도와줘요. 서버 없이 폰 한 대로 되고 자료도 많아서 처음 시작하는 사람에게 추천한대요. 윤자동 팀의 컨설턴트 박구조도 이걸로 '카나리'라는 AI 챗봇을 만들었는데, 클과장과 거의 똑같이 동작한다고 해요.

봇 전용 폰은 알뜰폰으로 월 500원~1,000원 요금제 번호를 하나 개통하고, 당근에서 액정 깨진 안드로이드 폰을 만 원 안팎에 사서 마련하라고 해요. 액정이 깨져도 작동만 하면 되니까요.

카카오 CLI는 맥 카톡을 명령어로 읽고 검색하고 보내는 오픈소스예요. 처음 보여 준 공지 시연이 바로 이거였어요. 라이브 중에 "오늘 단톡방 대화를 카카오 CLI로 읽어서 닉네임별 글자 수를 표로 정리해 줘"라고 시키자, AI가 DB를 조회해 시간대별 대화 요약과 통계를 채팅방에 올렸어요(클과장이 대화 지분 74%를 차지했죠). 설치 명령어에서 막히는 사람이 많은데, 이제는 링크를 주고 "분석해서 설치해 줘"라고 하면 AI가 해 준다는 게 윤자동의 설명이에요.

윈도우라면 PC 카톡보다 안드로이드 에뮬레이터를 권해요

윈도우 PC 카톡도 Win32 API로 창과 버튼을 직접 제어할 수 있고, 카카오톡 MCP 같은 오픈소스도 있어요. 그런데 윈도우에서는 자동화가 창을 가로채는 등 불편한 점이 많아요. 그래서 추천하는 건 LD플레이어 같은 PC용 안드로이드 에뮬레이터에 카톡과 메신저봇R을 까는 방식이에요.

정리하면 남는 안드로이드 폰이 있으면 메신저봇R, 맥을 켜 둘 수 있으면 카카오 CLI, 윈도우뿐이면 에뮬레이터+메신저봇R, 24시간 안정적으로 돌려야 하면 리눅스 서버+아이리스예요.

클과장은 미니 PC 속 리눅스에서 돌아가요

클과장은 회사에 둔 미니 PC에서 돌아가요. 윤자동은 2년 전에 10만 원 남짓에 샀는데, 비슷한 모델이 지금은 40만~50만 원대로 올랐다고 해요. 윈도우를 지우고 리눅스를 깔아 24시간 켜 두는 용도로 충분하대요.

리눅스 위에 리드로이드(Redroid)로 안드로이드를 띄우고, 카카오톡 앱 하나와 아이리스(Iris)라는 오픈소스를 설치하는 구조예요. 아이리스는 카톡 DB 변화를 감지해 메시지를 읽고, 내부 봇 서버로 넘기고, 서버가 만든 답장을 카톡으로 보내요. 미러링한 화면을 보면 옛날 안드로이드에 앱이라곤 카카오톡 하나뿐이고, 계정 이름엔 예전 이름인 '윤봇'이 남아 있어요.

미니 PC 대신 VPS(가상 서버)를 빌리는 방법도 있어요. 램 8GB면 적당하고 16GB면 넘친대요. 예로 든 상품은 월 13,000원대였고요. 운영비는 한 달 만 원 미만이에요. 기존 Claude 유료 구독을 연결해 쓸 수 있어 API 키를 따로 받을 필요가 없고, 사용량이 적으면 API가 월 1,000원 수준으로 더 쌀 수도 있대요.

관리 페이지에서 보이는 클과장의 판단 과정

이 라이브에서 처음 공개한 게 클과장 관리 대시보드예요. 방마다 백엔드를 Claude로 쓸지 Codex로 쓸지, 모델(Sonnet·Opus·Haiku), 추론 강도, 10분당 최대 답변 수, 질문이 아닌 말에 끼어들 확률까지 설정해요. 수강생 방에는 강의 자료를 TXT로 넣어 두고 "4.2 강의 자료에 있어요"처럼 자료 번호를 짚어 주는 맞춤 답변을 24시간 해요.

가장 공들인 부분은 답할지 말지를 정하는 판정이에요. 자막상 '재부'라고 부르는 판단 필터 AI를 앞단에 넣었거든요. "클과장 MBTI 뭐야"처럼 이름을 부르면 필터를 건너뛰고 바로 답변 생성으로 가요. 짧은 질문 뒤에는 긴 페르소나 프롬프트와 과거 대화가 붙고, 입력 4,900토큰·출력 300토큰으로 "저는 ENFJ예요"라는 답이 나와요. 추론에 걸린 시간은 6초였고요.

이름을 부르지 않은 말은 필터가 점수를 매겨요. "역시 윤자동 님 짱입니다"는 점수가 낮아 그대로 침묵하고, 0.4점을 넘어야 다음 단계로 가요. "쿠폰이 실물 쿠폰일까요?"는 0.658점으로 통과했지만, LLM이 "앞서 쿠폰을 언급한 사람의 몫"이라며 다시 침묵을 골랐어요. 필터와 LLM이 두 번 거르는 구조인 셈이죠. 최근 3일 동안 메시지 약 2,100개 중 1,000개가 LLM 단계까지 갔고 실패는 8개뿐이었대요.

끊기지 않게 굴리는 운영 노하우와 규칙

카톡이 강제 로그아웃되거나 구독 인증이 만료되면 Slack으로 알림이 오고, '윤비서'라는 에이전트가 카톡을 다시 띄워 로그인을 유지해요. 1:1 방에서는 클과장이 매일 새벽 4시 30분에 하루 대화를 회고하고 스스로 버전을 올려요(현재 버전 3).

운영 규칙은 봇 전용 계정을 꼭 따로 만들 것부터예요. 윤자동은 본 계정으로 봇을 돌리다 영구 정지를 당했고, 이유도 "내부 사정이라 공개할 수 없다"는 답만 받았대요. 그 밖에 봇이라고 알리기, 답장 속도와 횟수 제한, 개인정보 관리, 바로 끌 수 있는 스위치가 필요하다고 해요.

카톡방을 키우고 회사 업무를 돌리는 데도 쓰여요

카톡방은 극초반에 들어오는 만큼 빠져나가서 키우기가 가장 어려운데, 봇을 넣어 두면 사람들이 봇과 대화하며 머문대요. 윤자동의 방도 몇백 명일 때부터 '윤봇'이 있었어요. 법인카드 결제 문자를 카톡 알림으로 바꿔 재무팀도 바로 보게 했고, 카톡 발주 자동화와 출퇴근 기록(카톡에 출근을 치면 구글 시트에 시간이 찍히는 방식)을 다른 회사에 도입해 준 적도 있대요.

윤자동은 이런 우회로가 필요한 이유를 카카오의 폐쇄적인 정책에서 찾아요. 텔레그램·Slack·디스코드·왓츠앱은 API로 메시지를 바로 보낼 수 있는데 카카오톡은 API를 열어 주지 않으니까요.

에이전트 시대에는 "할 줄 아는 사람"이 살아남는다고 봐요

후반에는 카톡 밖의 자동화도 보여 줘요. 프롬프트 한 줄로 만든 축제 쇼츠, 로컬 음악 모델(자막 표기 YUE2)로 만든 테마곡 뮤직비디오, 휴대폰 갤러리의 동물원 사진·영상을 Claude Code가 분석해 자막까지 단 가족 영상이에요. 지시에 든 시간은 3~10초였다고 해요.

윤자동은 ChatGPT 초기를 "똑똑한 검색 엔진"으로, 지금을 에이전트가 메일 발송·영상 업로드·광고 세팅까지 직접 해내는 시대로 봐요. 그래서 AI를 잘 쓰는 사람이 되거나, 오프라인 영업처럼 AI가 아직 못 하는 영역에서 뛰어난 사람이 되거나 둘 중 하나여야 한다고 직원들에게도 자주 말한대요.

핵심 인사이트

  • 카톡봇은 읽기·생각하기·보내기 3단계로 나눠 보면 쉬워져요: 어떤 환경에서 '읽기'를 할지만 정하면 나머지는 AI와 오픈소스로 채울 수 있어요. 안드로이드 폰, 맥, 윈도우, 서버 중 내 장비에 맞는 경로부터 고르면 돼요.
  • 잘 만든 봇은 답하는 능력보다 입 다무는 판단이 핵심이에요: 클과장은 판단 필터 점수(기준 0.4)와 LLM 판단으로 두 번 걸러 "윤자동 님 짱입니다" 같은 말엔 침묵해요. 질문이 아닌 말에 끼어들 확률까지 따로 설정할 만큼 '언제 말하지 않을지'에 공을 들였어요.
  • 정지 위험은 감수하고 시작해야 해요: 윤자동은 문제될 만큼 쓰지 않으면 정지가 잦지는 않다고 하면서도, 스팸 없이 답변용으로만 쓰다 본 계정이 영구 정지된 경험을 털어놔요. 정지된 카톡은 다시 쓸 수 없으니 전용 계정과 바로 끌 수 있는 스위치를 먼저 갖추라는 거예요.

오늘 당장 해볼 것

  1. 카톡에서 하루에 반복하는 일(같은 공지 여러 방에 보내기, 발주 메시지 엑셀로 옮기기, 같은 질문 답하기)을 세 가지만 적어 보세요. 이 목록이 봇 기획서의 출발점이 돼요.
  2. 남는 안드로이드 폰이 있다면 메신저봇R을 설치하고, AI에게 "특정 키워드가 오면 정해진 링크로 답하는 스크립트를 짜 줘"라고 요청해 보세요. 서버 없이 가장 빨리 '읽고 보내기'를 체험할 수 있어요.
  3. 봇을 굴리기 전에 알뜰폰 저가 요금제로 봇 전용 번호부터 만들어 두세요. 봇이 엉뚱한 답을 하거나 계정이 정지돼도 본 계정은 지킬 수 있어요.
