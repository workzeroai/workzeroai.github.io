핵심
  • 무료인 것보다 에이전트가 직접 돌릴 수 있다는 점이 커요
  • 연결은 한 번 해 두고 여러 에이전트가 같이 써요
  • 답 하나 대신 100개를 붙여서 골라요

한 줄 요약

Jack Roberts가 지금 GitHub에서 뜨고 있는 오픈소스 저장소 10개와 보너스 두 개를 골라 소개해요. 어도비 제품군을 통째로 다시 만든 무료 앱부터 AI 에이전트 전용 브라우저, 100개의 답을 토너먼트로 붙이는 스킬, 보안 감사 스킬까지 "에이전트에게 맡길 수 있는 도구"가 한 줄로 정리돼 있어요.

전체 내용 정리

어도비 제품군을 무료 오픈소스로 다시 만든 앱이 이번 달에만 두 개 나왔어요

Jack은 예전에 기술 스타트업을 세워 매각했고 지금은 자기 AI 스타트업을 만들고 있다고 소개해요. 첫 번째로 꺼낸 건 어도비 제품군 전체를 오픈소스로 다시 만든 앱 묶음이에요. 포토샵 자리에는 포토크래프트(Photocraft), 라이트룸 자리에는 라이트크래프트(Lightcraft), 프리미어 프로 자리에는 필름크래프트(Filmcraft)가 있어요. 이펙트크래프트, 벡터크래프트, PDF크래프트, 워드크래프트, CAD크래프트까지 있어서 Jack 표현대로 "이름만 대면 다 있는" 셈이죠.

설치는 간단하대요. 링크를 열고 Claude에게 "포토크래프트 설치해서 내 컴퓨터에서 열어 줘"라고 말하면 Claude가 알아서 처리해 준다고 해요. Jack은 친구에게 필름크래프트 화면을 보여 주면서 프리미어 프로라고 했더니 친구가 전혀 눈치채지 못했대요. 명령어 체계가 똑같고 복사·붙여넣기, 파일 드래그도 다 된다고 해요. 레이어 구성이나 마스크 추가처럼 포토샵에서 하던 작업도 거의 다 할 수 있대요.

10일 만에 GitHub 별 39,000개를 받았다고 해요. Jack이 꼽는 멋진 점은 이 앱들이 무료 오픈소스이면서 에이전트가 직접 실행할 수 있는 전문가용 디자인 앱이라는 거예요. 그래서 비용도 아낄 수 있대요. 실제로 Claude에게 "이미지 크기를 키우고 배경을 파란색과 노란색 그라데이션으로 바꿔 줘"라고 시키자, Claude가 앱을 열고 레이어를 다루며 배경색을 바꾸는 장면을 보여 줘요. 모두 러스트(Rust)로 만들어졌고 VectorCraft 웹사이트에서 맥·윈도우용으로 내려받을 수 있대요.

참고로 Jack은 컴퓨터 제어(computer use) 작업만 놓고 보면 현재로서는 ChatGPT가 가장 낫다고 본대요. 물론 원하는 도구를 쓰면 된다는 말도 덧붙이고요.

두 번째는 Compositor라는 도구예요. 레이어에 직접 접근할 수 있어서 사진이 바뀌는 과정을 눈으로 볼 수 있대요. Jack은 이번 달에만 두 사람이 포토샵을 다시 만든 셈이라며 "어떤 기술이라도 재현할 수 있는 100% 무료 저장소의 시대"에 들어섰다고 말해요.

X(트위터) 출시 게시물 하나로 200만 조회수를 기록했대요. Jack은 앞의 포토크래프트와 비교하면 UI는 Compositor 쪽이 조금 더 낫다고 평가해요. 색 구성이 마음에 들고 버튼도 약간 크다고요. 다만 둘 다 기능은 훌륭하니 취향대로 고르면 된다고 해요.

화면을 뺏지 않는 에이전트 브라우저 Ego Light, 앱 구조를 묻는 Rear

세 번째는 AI 에이전트를 위해 만든 브라우저, Ego Light예요. 많이 언급되진 않았지만 GitHub에서 반응이 좋다고 해요. light.ego.app에서 완전히 무료로 쓸 수 있대요.

핵심은 화면을 빼앗지 않고도 에이전트가 웹을 돌아다닌다는 점이에요. Jack은 대부분의 AI가 컴퓨터를 제어하는 동안 사람이 다른 일을 못 하게 만들거나, 자체 브라우저를 쓰더라도 내가 평소 로그인해 둔 계정이 없어서 불편하다고 짚어요. Ego Light는 이 두 문제를 풀어 준대요.

데모에서는 특정 X 계정의 주요 게시물을 스크랩하라고 시켜요. 고정 게시물·리포스트·라벨 붙은 게시물은 빼라는 조건까지 줬는데, 에이전트가 페이지를 보며 알아서 판단해 정보를 가져와요. 각 작업이 개별 탭에서 돌아가서 여러 검색을 동시에 돌릴 수 있고 그 위에 원하는 모델을 연동할 수 있다고 해요.

네 번째 Rear는 앱이 어떻게 작동하는지 질문할 수 있게 해 주는 도구예요. 개선하고 싶은 앱이 있는데 UI와 로직, 데이터만 봐서는 구조를 알기 어려울 때 쓰는 거죠. Jack 말로는 별 65,000개를 받았고 이번 주 GitHub에서 가장 빠르게 크는 저장소래요.

설정은 명령어 하나면 된대요. 예를 들어 메모 앱에서 검색 기능이 어떻게 돌아가는지 물으면 근거를 보여 주고 내 프로젝트에도 같은 기능을 만들 수 있게 해 준다고 해요.

21st.dev를 붙이면 디자인이 한 단계 올라가요

다섯 번째는 21st.dev, 디자인 컴포넌트 라이브러리예요. Jack은 "디자인 컴포넌트를 위한 윌리 웡카의 초콜릿 공장"이라고 불러요. Claude, ChatGPT 등 원하는 모델과 함께 쓸 수 있고 커뮤니티 컴포넌트나 오늘 인기 있는 컴포넌트도 둘러볼 수 있어요. 마음에 드는 걸 고른 뒤 프롬프트를 복사해 Claude에게 "내 노트북 앱에 이걸 만들어 줘"라고 붙여 넣으면 된대요.

Jack은 자기 음성-텍스트 변환 스타트업 Glider의 UI를 다시 디자인할 때 Claude Code 안에서 21st.dev를 많이 썼다고 해요. 그런데 더 좋은 방법이 있어요. 21st.dev MCP를 연결하면 Claude가 거대한 컴포넌트 도서관에 직접 접근하거든요. 푸터, 내비게이션 바, 기능 섹션, 가격표 중 뭐가 필요하든 Claude가 가장 어울리는 UI 에셋을 알아서 가져온대요. 그래서 Jack은 더는 직접 검색할 필요가 없다고 말해요.

연결 방법도 소개해요. 21st.dev 왼쪽 메뉴에서 CLI 및 MCP를 누르고 브라우저를 고른 다음, 나온 명령어를 복사해 터미널에 붙여 넣으면 된대요. Jack은 직접 디자인할 수도 있지만 현존하는 최고의 디자인 원칙을 찾아 연결해 쓰라고 권해요.

스킬을 찾아 주는 스킬, 여러 에이전트를 부리는 Orca, 보너스 Zapier MCP

여섯 번째는 새로운 스킬을 찾아 주는 스킬이에요. ChatGPT나 Claude에게 "멋진 파워포인트를 만들 스킬이 필요해"라고 말하면 이 스킬이 쓸 만한 최고의 스킬을 찾아 준대요. Vercel Labs가 만든 스킬로, 현재 skills.sh에서 가장 인기 있는 스킬이라고 해요.

여기서 Jack은 중요한 팁을 하나 줘요. 어떤 스킬이든 ChatGPT나 Claude로 먼저 확인하지 않고는 설치하지 말라는 거예요. 훌륭한 개발자도 많지만 그렇지 않은 사람도 분명 있으니까요. 개인 컴퓨터에 깔기 전에 저장소에 뭐가 들어 있는지 먼저 이해하는 게 좋다고 해요.

일곱 번째 Orca는 한 명의 사람과 다수의 에이전트라는 개념의 저장소예요. 별이 약 89,000개로 거의 9만 개에 달하는데 대부분이 이번 달에 붙었대요. 여러 에이전트에게 일을 나눠 주면 동시에 각자 작업을 끝내고 끝난 결과를 나란히 놓고 검토할 수 있어요. URL을 클론한 뒤 에이전트마다 개별 작업을 주면 된대요.

보너스로 Zapier MCP도 소개해요. Jack은 Zapier가 인터넷에서 유행하기 몇 년 전에 첫 스타트업을 초기에 Zapier로 만들었대요. 에이전트를 여러 개 쓰게 될수록 각자 Gmail, 캘린더, Slack 같은 연결이 필요해지는데, Zapier MCP를 일종의 만능 열쇠처럼 쓰면 한 번 연결해 둔 걸 어디서든 쓸 수 있다고 해요. Airtable, Canva, Skool처럼 바깥에서 바로 접근하기 어려운 서비스도 붙일 수 있고요. 예를 들어 Gmail에 대해 "이메일 보내기는 허용, 이건 안 돼"처럼 권한을 개별로 정할 수 있다는 점도 짚어요.

100개의 답을 토너먼트로 붙이는 Arena, 게임 모더, Cloudflare 보안 감사 스킬

여덟 번째는 Arena 스킬이에요. Jack은 100명을 지도에 떨어뜨려 최후의 1인을 가리는 포트나이트에 비유해요. 같은 질문에 대한 100개의 답을 두 개씩 맞붙여 비교하고 이긴 답이 다음 라운드로 올라가 최종 답이 남을 때까지 반복하는 방식이에요. 마지막에는 어떤 답이 왜 이겼고 어떤 답들을 제쳤는지까지 보여 준대요.

출발점은 단순해요. AI에게 같은 질문을 두 번 하면 다른 답이 두 개 나오잖아요. 그러면 100번 물어서 그중 최고를 고르면 어떨까 하는 거죠. 사용법은 코드를 복사해 Claude에 붙여 넣고 "아레나 스킬을 써서 이 질문에 답해 줘"라고 하면 된대요. 인스타그램에서는 반응이 폭발적인데 유튜브에서는 거의 언급되지 않았다고 해요.

아홉 번째는 Rohan Remade(로한 리메이드)라는 사람이 만든 범용 모더 플러그인이에요. 게임을 주면 모드를 만들어 준대요. 아직 초기 단계지만 가지고 놀기 재미있는 도구라고 Jack은 평가해요. 그리고 "무엇이든 해체하고 무엇이든 효과적으로 구축할 수 있는 소프트웨어의 새로운 시대"에 들어서고 있다는 걸 기억하라고 말해요.

열 번째는 Cloudflare의 보안 감사 스킬이에요. 코딩 에이전트를 보안 감사 도구로 바꿔 주는 스킬이죠. 정찰, 커버리지 기반 탐색, 후보 검증, 구조화된 출력, 독립적인 기록 검증을 거치며 여러 에이전트를 조율한대요. Jack은 클라이언트 앱이나 실서비스용 결과물을 내보내기 전에 꼭 돌려 보라고 권해요.

마지막 보너스는 글을 사람이 쓴 것처럼 바꾸는 SlotMonster예요

마지막으로 지난 영상에서도 소개했던 SlotMonster를 다시 꺼내요. 어떤 텍스트든 사람이 쓴 것처럼 바꿔 주는데, 실제로 전환을 끌어내는 마케팅·영업 관습으로 학습됐다는 게 차별점이래요.

예시가 와닿아요. "신뢰할 수 있고 튼튼하며 오래 간다"는 말이 "모든 싱글마다 6개의 못을 사용한다"로 바뀌어요(싱글은 지붕에 덮는 판, 지붕널이에요). "업계 최고의 자재를 활용하여 타의 추종을 불허하는 보호 기능을 제공합니다"라는 문장도 "바람, 우박, 햇빛에 대한 테스트를 거친 제조사의 자재만을 사용합니다"라는 구체적인 문장이 돼요. 추상적인 칭찬을 구체적인 사실로 바꿔 준다는 거죠.

핵심 인사이트

  • 무료인 것보다 에이전트가 직접 돌릴 수 있다는 점이 커요: Jack이 포토크래프트 같은 앱에서 꼽은 멋진 점은 무료 오픈소스이면서 에이전트가 직접 실행할 수 있는 전문가용 디자인 앱이라는 거예요. 실제로 Claude에게 말로 시켜 배경을 바꾸는 편집까지 맡겨 보여 줬어요.
  • 연결은 한 번 해 두고 여러 에이전트가 같이 써요: Jack은 에이전트를 여러 개 쓰게 될수록 각자 Gmail, 캘린더, Slack 같은 연결이 필요해진다고 봐요. Zapier MCP로 한 번 설정해 두면 어디서든 쓸 수 있고 권한도 개별로 정할 수 있어서, 시간을 엄청나게 아껴 준다는 게 Jack의 평가예요.
  • 답 하나 대신 100개를 붙여서 골라요: Arena 스킬은 AI에게 같은 질문을 두 번 하면 다른 답이 나온다는 점에서 출발해요. 그렇다면 100번 물어서 토너먼트로 최고의 답을 고르자는 거죠. Jack은 더 어렵고 흥미로운 질문에 써 보고 성능을 직접 확인해 보라고 권해요.

오늘 당장 해볼 것

  1. 자주 쓰는 마케팅 문구 하나를 골라 Claude에게 "추상적인 칭찬을 숫자와 사실로 바꿔 줘"라고 시켜 보세요. SlotMonster 예시처럼 "튼튼하다"가 "못 6개"로 바뀌는 차이를 직접 보면 상세페이지 카피를 고칠 기준이 생겨요.
  2. 새 스킬이나 GitHub 저장소를 깔기 전에 저장소 주소를 Claude나 ChatGPT에 주고 "이 저장소가 내 컴퓨터에서 하는 일과 위험 요소를 정리해 줘"라고 물어보세요. Jack이 강조한 설치 전 점검을 습관으로 만들 수 있어요.
  3. 랜딩페이지나 사내 도구를 Claude로 만들고 있다면 21st.dev에 들어가 CLI 및 MCP 메뉴에서 연결 명령어를 받아 붙여 보세요. 헤더나 가격표 하나만 바꿔 봐도 디자인 수준이 얼마나 달라지는지 바로 비교돼요.
