핵심
  • 스킬은 전문가의 질문 순서까지 담고 있어요

  • 스킬을 묶으면 마케팅 직원이 돼요

한 줄 요약

해외 마케팅 에이전시 운영자가 자기 노하우를 스킬 파일로 공개해 뒀는데, 투쏠은 이 스킬을 Claude에 올려 콘텐츠 전략과 랜딩 페이지 카피를 뽑고, 같은 스킬 다섯 개를 묶어 Claude Code 서브 에이전트(마케팅 직원)까지 만드는 과정을 보여 줘요.

전체 내용 정리

전환율 최적화 전문가의 노하우가 스킬 묶음으로 공개돼 있어요

투쏠이 이번 영상에서 들고 나온 건 마케팅 스킬 모음이에요. 해외에서 전환율 최적화 마케팅 에이전시를 운영하는 사람이 자기 마케팅 노하우를 전부 스킬로 만들어 GitHub에 올려 뒀다고 해요. 투쏠이 찾아보니 그쪽에서는 꽤 유명한 사람이라고 합니다.

스킬은 큰 섹션으로 나뉘어 있고, 그 안에 항목이 여러 개 들어 있어요. 투쏠이 훑어본 목록만 해도 A/B 테스트, 광고 크리에이티브, SEO 분석, 분석·트래킹, 콜드메일, 콘텐츠 전략, 카피라이팅, 카피 에디팅, 고객 조사, 이메일 시퀀스, 폼 전환율 최적화, 리드 마그넷, 페이지 전환율 최적화, 레퍼럴 프로그램까지 이어져요. 마케팅 심리학이나 마케팅 아이디어 같은 항목도 있고요.

투쏠은 이걸 직접 써 보니 꽤 유용했고, 해외에서 볼 법한 유명 마케팅 노하우와 느낌이 비슷하다고 말해요. 요즘은 이 스킬로 자기만의 마케팅 전략을 많이 짜고 있다고 하고요. 그중에서도 콘텐츠 전략, 카피라이팅, 리드 마그넷, 폼 전환율 최적화를 가장 자주 쓴다고 합니다. 나머지 항목은 아직 다 열어 보지 못해서 하나씩 도장 깨기를 하는 중이라고 해요. 목록 중에는 용도를 잘 모르겠다며 넘어간 항목도 하나 있었어요.

오늘 영상에서 보여 주는 건 딱 두 가지예요. 이 스킬을 Claude에서 쓰는 방법, 그리고 Claude Code로 에이전트를 만드는 방법입니다.

Claude에 스킬을 올리는 방법은 다운로드 한 번이면 돼요

스킬은 먼저 Claude에 넣어 줘야 쓸 수 있어요. 투쏠이 보여 준 순서는 이렇습니다. 왼쪽 아래에서 설정으로 들어가 기능 메뉴를 열고, 아래로 내리면 스킬 항목이 나와요. 거기서 사용자 지정 쪽으로 들어가면 내 스킬을 모아 두는 화면이 열립니다.

설명란에 걸린 GitHub 저장소에서 원하는 스킬 폴더를 열면 안에 SKILL.md 파일이 있어요. 이 파일 화면 오른쪽의 다운로드 버튼을 누르면 파일이 내려받아집니다. 그다음 Claude 스킬 화면에서 플러스 버튼을 눌러 스킬 만들기, 스킬 업로드를 고르고, 방금 받은 파일을 그대로 끌어다 놓으면 끝이에요. 투쏠은 이미 올려 둔 스킬이 있어서 이 과정은 생략했고, 없다면 필요한 스킬을 하나씩 받아서 넣으면 된다고 안내합니다.

투쏠이 말하는 쓸모는 이렇습니다. 마케팅 심리가 궁금하면 책을 볼 수도 있지만, 이렇게 스킬로 넣어 두면 바로 활용할 수 있어요. 광고 전략을 같이 짜 보고 싶을 때도 같은 방식으로 해당 스킬의 SKILL.md를 받아 올리면 됩니다.

쓰는 법도 간단해요. Claude 채팅창에서 슬래시를 누르면 내가 올려 둔 스킬 목록이 뜨고, 거기서 고르면 됩니다.

콘텐츠 전략 스킬은 질문부터 던지고 나서 답을 줬어요

첫 시연은 콘텐츠 전략 스킬이에요. 투쏠은 슬래시로 스킬을 고른 뒤, 지금 Claude Code 관련 콘텐츠를 올리고 있는데 어떤 전략으로 확장할 수 있을지 이 스킬을 활용해서 제안해 달라고 보냈어요. 콘텐츠를 만들다 막혔을 때 그냥 슬래시 커맨드를 켜고 물어보면 된다는 설명이 붙었습니다.

Claude는 스킬 파일을 먼저 읽고 나서 곧바로 답하지 않고 컨텍스트를 물어봤어요. 투쏠 말로는 컨텍스트 파일이나 저장된 메모리가 따로 없는 상태라서 당연한 반응이라고 합니다. 처음에는 가장 가능성이 높은 시나리오를 가설로 하나 보여 주고, 답을 듣고 나서 다듬겠다는 식으로 진행됐어요.

투쏠은 질문에 이렇게 답했어요. 포지셔닝은 한국에서 Claude Code 1인자, 주요 타깃은 비개발 직군 사장님이나 1인 크리에이터, 지금 가장 약한 지점은 차별화된 시그니처 콘텐츠입니다. 말 그대로 Claude에게 내 컨텍스트를 주는 과정이고, 그래야 스킬이 더 잘 맞춰진다는 거예요.

결과로는 채널별 비중 제안이 나왔어요. 투쏠이 읽어 준 내용으로는 유튜브 롱폼을 40%, 뉴스레터를 25%로 두고, 나머지는 증거 콘텐츠와 Claude Code 기초 콘텐츠 등으로 나누는 구성이었습니다. 유튜브 전략, 인스타그램 활용, 뉴스레터에 케이스 스터디를 올리는 방향도 함께 나왔고요. 시그니처 콘텐츠를 만드는 방법으로는 이름을 붙인 프레임워크를 반복해서 쓰라는 제안이 있었어요. 자신의 노하우를 플레이북으로 만들고, AI가 대신하는 시스템으로 바꾸는 4단계 같은 주제를 다뤄 보라는 제안도 나왔다고 합니다.

카피라이팅 스킬은 형편없는 카피를 먼저 진단해 줬어요

두 번째는 카피라이팅 스킬이에요. 이번에는 바로 일을 시키지 않고, 이 스킬을 어떻게 쓸 수 있는지 읽어 보고 알려 달라고 물었어요. Claude의 설명은 이랬습니다. 웹사이트나 랜딩 페이지에서 행동을 끌어내는 전환 카피를 쓰는 스킬이고, 구조는 히어로 섹션, 소셜 프루프, 문제 제기, 해결, 작동 방식, 이의 해소, FAQ, 마지막 CTA 순서예요. 커뮤니티 모집 랜딩 페이지를 쓰는 방법도 안에 들어 있다고 했어요.

스킬을 부를 때 알려 줘야 할 정보도 안내해 줬어요. 페이지 종류(랜딩인지 가격 페이지인지), 이 페이지에서 원하는 단 하나의 행동, 누가 보러 오는지, 기존 카피, 차별점이에요. 투쏠은 여기에 맞춰 입력하되, 일부러 허술하게 채웠습니다. 목적은 진단 신청, 대상은 Claude Code를 제대로 배우고 싶은 사람, 현재 카피는 짧은 한 줄, 차별점은 크리에이터가 알려주는 활용법 정도였어요.

Claude는 카피를 쓰기 전에 현재 상태부터 진단했어요. 투쏠이 전하는 핵심은 세 가지예요.

  • 지금 카피는 나의 단어로 쓰여 있으니 고객의 단어로 바꿔야 한다는 지적
  • 타깃이 너무 모호하다는 지적
  • 신청한 사람이 30일, 90일 뒤에 어떻게 달라져 있는지가 빠져 있다는 지적

투쏠은 이 모호한 부분을 일부러 만든 건데도 정확히 짚어 줘서 인상 깊었다고 해요. 진단 끝에 나온 V1 카피 중 하나는 머릿속에만 있던 노하우를 Claude Code로 시스템으로 만들자는 방향이었고, 개발자가 아닌 크리에이터가 가르치는 진짜 쓰는 Claude Code라는 카피도 있었어요. 서브 헤드라인은 30분 무료 진단에서 워크플로 하나를 골라 Claude Code 시스템으로 어떻게 자동화할지 함께 설계한다는 내용이었고, 투쏠은 30분, 하나, 함께 설계처럼 모든 게 구체적이라고 평가했어요.

그 구체성이 전부 카피라이팅 스킬 안에 들어 있는 원칙에서 나온다는 게 투쏠의 설명이에요.

그다음 투쏠이 정보를 더 줬어요. 1대1 무료 진단이고, 소셜 프루프 훅이 있으며, 다음 단계는 1대1 컨설팅 판매라고요. Claude는 V2를 쓰기 전에 전략부터 다시 잡았는데, 이 페이지가 무료 진단 신청 페이지처럼 보여도 실제로는 컨설팅 판매 퍼널의 1단계라고 정리했어요. 그렇게 나온 V2는 대상이 훨씬 또렷해졌고, 1인 크리에이터를 위한 Claude Code 적용 방법이라는 문구가 앞에 서요. 서브 헤드라인에는 내가 줄 수 있는 핵심 정보가 들어갔고, 섹션 구성은 후기와 프루프, 안내 순으로 이어졌어요.

투쏠이 강조하는 건 이 흐름이에요. 만들고 싶은 상품을 마케팅 스킬과 함께 질문을 주고받으며 다듬으면 더 잘 만들 수 있고, 마케팅이 가물가물한 사람도 이 질문 과정에서 자기 마케팅을 고도화할 수 있다는 거죠.

스킬 다섯 개를 묶어 Claude Code 마케팅 서브 에이전트를 만들었어요

여기까지가 Claude 쪽이었고, 이제 에이전트를 만들어요. 투쏠은 편집기 안티그래비티에서 폴더를 하나 만들고, 그 폴더 기준으로 터미널에서 Claude Code를 켰습니다. 익스텐션으로 쓸 수도 있지만 이번에는 터미널을 골랐어요. 먼저 플랜 모드로 바꿔서 에이전트를 같이 설계하는 방식이에요.

투쏠이 입력한 지시는 대략 이렇습니다. 서브 에이전트를 하나 만든다, 목적은 마케팅 프로세스의 전략을 짜 주는 것이다, 내가 주제를 던지면 그 주제의 콘텐츠 전략과 메인 헤드라인, 본문, CTA 구조를 짜고 그걸 통해 줄 리드 마그넷까지 설계하라는 거예요. 그리고 에이전트가 반드시 쓸 스킬로 콘텐츠 전략, 카피라이팅, 마케팅 아이디어, 리드 마그넷, 마케팅 심리 스킬 다섯 개를 지정했어요. 이걸 바탕으로 계획부터 세워 보라고 시켰습니다.

Claude Code가 낸 계획에는 서브 에이전트 구축 계획과 최종 디렉터리 구조, 작업 목록이 들어 있었어요. 구조는 프로젝트 안에 에이전트 MD 파일과 skills 폴더만 두는 깔끔한 형태였습니다. 투쏠은 원하는 대로 설계가 잘 됐다고 보고, 바이패스 퍼미션을 켜서 바로 구축을 시켰어요. 이 구조는 서브 에이전트 개념이고, CLAUDE.md 같은 파일까지 더 들어가야 에이전트 구조가 한층 안정적이라는 말도 덧붙였어요. 이번 영상에서는 CLAUDE.md를 넣지 않아서 마지막에 따로 짚어요.

구축이 끝나자 Claude Code 세션을 시작하면 에이전트가 자동으로 인식된다는 안내가 떴어요. 투쏠은 Claude Code를 한 번 나갔다가 다시 켰습니다. 에이전트가 제대로 인식되는지 확인하는 단계예요.

에이전트에 주제 하나만 던졌더니 전략, 카피, 리드 마그넷이 한 번에 나왔어요

시험 주제는 국내 1인 SaaS 창업자를 위해 노션으로 고객을 관리하는 방법을 소재로 마케팅 전략을 짜 달라는 요청이었어요. 에이전트는 마케팅 전략 스킬을 먼저 쓰고, 이어서 카피라이팅과 리드 마그넷 스킬을 차례로 불러 썼습니다. 여러 스킬을 혼자 판단해서 번갈아 쓰는 모습이 화면에 그대로 보였어요.

결과에서 투쏠이 짚은 항목은 이렇습니다.

  • 콘텐츠 전략: 바이럴용 70, 공유용 30 비율. 검색량은 작지만 구매 의도가 높은 키워드를 중심에 두는 안
  • 배포: 디스콰이엇과 긱뉴스에 만드는 과정을 메타 콘텐츠로 공유
  • 리드 수집 후 7일, 14일 단계로 자동화
  • 토스페이와 스트라이프 결제 데이터를 노션에 연동하는 아이디어
  • 메인 카피: "허브스팟 없이도 1인 창업자가 고객 327명을 노션 한 장으로 관리하는 법"
  • 서브 헤드라인: 문의 응대, 토스 결제, 트라이얼 종료 알림까지 도구 다섯 개를 따로 쓰지 말고 노션 한 장에서 끝내라는 메시지
  • 본문은 7블록 구조, 그 밖에 리드 마그넷 설계, 심리 트리거, 1주차 실행 계획까지 포함

투쏠은 메인 카피를 두고 되게 좋은 헤드라인이라고 평가했어요. 1주차 실행 계획에는 노션 템플릿, 시나리오, 녹화 같은 작업이 들어 있었고요. 투쏠은 설계한 대로 잘 나왔다고 정리합니다.

한계도 하나 짚었어요. 스킬 파일이 미국 기준으로 만들어져서 토스페이나 스트라이프 같은 결제 연동은 컨텍스트가 부족해 보인다는 거예요. 이런 부분은 스킬 폴더나 CLAUDE.md에 들어가서 직접 고쳐 줘야 한다고 말합니다.

마무리에서 투쏠이 남긴 가장 실용적인 조언은 맥락 파일이에요. 에이전트에게 지금 어떤 사업을 하는지, 어떤 일을 하는지, 어떤 사람인지를 먼저 알려 줘야 한다는 거죠. 이 내용을 문서 파일로 저장해 두고, 마케팅 에이전트를 실행하기 전에 반드시 이 파일을 읽고 작업하도록 훅 같은 걸 걸어 두면 훨씬 유용하게 쓸 수 있다고 해요.

투쏠은 이번에 이렇게 구성해 봤으니 마케팅 스킬 MD 파일을 꼭 한번 써 보라고 권합니다.

핵심 인사이트

  • 스킬은 전문가의 질문 순서까지 담고 있어요: 시연에서 Claude는 바로 답하지 않고 컨텍스트부터 물었고, 카피라이팅 스킬은 카피를 쓰기 전에 현재 카피를 먼저 진단했어요. 스킬 덕분에 답의 품질뿐 아니라 일하는 순서도 달라진다는 점이 투쏠 시연의 핵심이에요.
  • 입력이 모호하면 Claude가 그 모호함을 짚어 줘요: 투쏠은 일부러 허술하게 넣었는데 타깃, 변화 시점, 고객의 단어가 빠졌다는 점을 정확히 짚어 줬어요. 내 마케팅이 가물가물한 사람일수록 질문을 주고받는 과정 자체가 공부가 된다는 이야기예요.
  • 스킬을 묶으면 마케팅 직원이 돼요: 스킬 다섯 개를 지정한 서브 에이전트는 주제 하나만 받아도 전략, 헤드라인, 본문 구조, 리드 마그넷, 실행 계획까지 만들어 냈어요. 스킬을 개별로 부르는 것과 에이전트가 알아서 골라 쓰는 것의 차이가 여기서 드러나요.
  • 해외 기준 스킬은 우리 환경에 맞게 고쳐 써야 해요: 결제 연동처럼 국내 서비스에 관한 맥락은 스킬에 없어서, 스킬 폴더나 CLAUDE.md에 직접 보강해야 한다고 투쏠은 말해요.
  • 내가 누구인지 담은 맥락 파일이 에이전트의 안정성을 좌우해요: 사업과 하는 일, 사람에 대한 정보를 파일로 저장하고 실행 전에 읽게 하면 결과가 한층 맞춰져요. 투쏠은 이번 영상에서 CLAUDE.md를 아직 넣지 않았다고 직접 인정했어요.

오늘 당장 해볼 것

  1. GitHub 저장소에서 콘텐츠 전략이나 카피라이팅 스킬 폴더를 열어 SKILL.md를 내려받고, Claude의 설정, 기능, 스킬 화면에서 스킬 업로드로 올려 보세요. 한 번 올려 두면 채팅창에서 슬래시로 바로 부를 수 있어요.
  2. 채팅창에 슬래시를 누르고 올려 둔 스킬을 고른 다음, 지금 하는 일을 설명하며 전략을 제안해 달라고 보내 보세요. Claude가 되묻는 컨텍스트 질문에 답하는 것만으로도 내 포지셔닝과 약한 지점이 정리돼요.
  3. 카피라이팅 스킬에는 페이지 종류, 원하는 단 하나의 행동, 누가 보러 오는지, 기존 카피, 차별점을 넣어 보세요. 투쏠처럼 지금 가진 카피를 그대로 넣으면 먼저 진단을 받아 볼 수 있어요.
  4. 폴더를 하나 만들고 터미널에서 Claude Code를 켠 뒤 플랜 모드로 서브 에이전트 설계를 시켜 보세요. 에이전트 목적, 내가 던질 입력(주제), 받고 싶은 결과물(헤드라인, 본문, CTA 구조, 리드 마그넷)과 반드시 쓸 스킬 이름을 적어 주면 돼요.
  5. 계획이 마음에 들면 실행을 시키고, 구축이 끝나면 Claude Code를 한 번 나갔다가 다시 켜서 에이전트가 인식되는지 확인하세요. 그다음 내 사업과 하는 일, 내가 어떤 사람인지를 적은 문서를 만들어 두고 에이전트가 먼저 읽게 하면 결과가 더 잘 맞아요.
